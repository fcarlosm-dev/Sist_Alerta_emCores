## 🎯 Sobre 

O **Sist_Alerta_emCores** é um sistema desenvolvido em código **Python**, que exibe mensagens de alerta com cores diferentes conforme o nível de água no reservatório. O sistema usa cores sólidas para indicar a capacidade real.
Por ser um projeto inicial, que não necessita de inserção de dados, pode sofrer alterações para aumentar a capacidade e dinamismo no monitoramento.
A ideia inicial é que aos poucos o projeto sofra evoluções que possam fazê-lo entrar em escala, tornando-o útil em locais que necessitam deste tipo de monitoramento.
Atualmente devido a eventos climáticos como El Niño que, de acordo com os especialistas, tende a ser o mais intenso, este projeto pode trazer benefícios em regiões que sofrem com a escasses ou excesso de água.
